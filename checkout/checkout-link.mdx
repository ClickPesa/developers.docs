## Introduction

The checkout link feature is for businesses and organizations with an app, website or software product who seek a streamlined method to accept online payments for their goods and services. By making an API request to our checkout link generation endpoint, merchants can create a unique checkout link from their apps, websites, or systems. Once generated, this link can process multiple payments, giving a notification each time a transaction is processed, with all transactions easily viewable in the ClickPesa dashboard. See [Common Use Cases](/checkout/common-use-cases) for where this fits your business.

## **How to Use the Feature**

To use this feature, you need a ClickPesa account with full KYC and the Checkout Link feature activated in your dashboard settings. For testing, you can use a sandbox account while completing registration and KYC with ClickPesa's compliance team.

### **Activating Checkout Link**

Activate Checkout Link under **Settings → Collection** in the Merchant Dashboard. See [Collection Settings](/dashboard/settings/collection) for the full walkthrough.

After activation, create checkout links and collect payments using the [Checkout Link API](/checkout/checkout-link-api).
