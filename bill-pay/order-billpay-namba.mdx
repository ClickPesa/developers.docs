An **Order BillPay Control Number** is a dynamic control number generated for a specific transaction or invoice. It’s designed for one-time use and is best suited for e-commerce, invoicing, or any scenario where a customer is making a payment tied to a unique order.

##  Generating Order BillPay Control Number
Each **Order BillPay Control Number** consists of:

- [Merchant BillPay-Namba](/bill-pay/billpay-namba): A 4-digit number assigned to you by ClickPesa.

- **Order Reference**: Any reference number used in the merchant’s system to identify the transaction or product.

To create a **Order BillPay Control Number**, concatenate your Merchant BillPay-Namba with the Order Reference

`[Merchant BillPay-Namba]` + `[Order Reference]` = `BillPay Control Number`

```text
Example:

Merchant BillPay-Namba: 1122
Order Reference: 231256
Order BillPay Control Number: 1122231256
```

## BillPay Payment Notifications  
You can receive payment notifications for your billpay numbers by setting up a [webhook](/home/webhooks). Alternatively, you can use the [Payment Query API](/api-reference/collection/querying-for-payments/querying-for-payments) using the order BillPay number to check payment status.


## Making Payment Using an Order BillPay Control Number

Customers can conveniently make payments using **Order BillPay Control Number** through Tanzania’s leading mobile money services such as Tigopesa, Airtel Money, Halopesa and M-Pesa, as well as CRDB SIM Banking (APP and USSD), CRDB Internet Banking and CRDB Wakalas.
