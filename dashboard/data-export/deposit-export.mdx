## Introduction

This feature simplifies the process of exporting your deposits data exactly how you want it. We've already organized the data for you, so all you need to do is choose which data you want and export it to Excel or CSV.

In this guide, we'll walk you through how to filter your deposits data to find exactly what you're looking for. Then, we'll show you how to export that data into an Excel or CSV file. It's a straightforward way to get the information you need, hassle-free. Let's dive in and get started!

### Export deposits as CSV

1. Login to your [merchant.clickpesa.com](https://merchant.clickpesa.com) account.
2. Navigate to Data Export and select Export Deposits as CSV card.

<Frame>
<img src="/images/knowledge-base/deposits-csv.png" alt="Deposits Csv" />
</Frame>

3. You should land to page called Export Deposits as CSV, with filters (Status and date preselected) and table and button to export and button for More Exports options.

<Frame>
<img src="/images/knowledge-base/SCR-20240212-ncoj.png" alt="Merchant Dashboard screenshot" />
</Frame>

4. You can use filters such as status and date range to return the actual data you want to export.

<Frame>
<img src="/images/knowledge-base/SCR-20240212-ncqi.png" alt="Merchant Dashboard screenshot" />
</Frame>

5. Upon clicking export browser will download a file called deposits.csv. It will look like this.

<Frame>
<img src="/images/knowledge-base/SCR-20240212-ndac.png" alt="Merchant Dashboard screenshot" />
</Frame>
