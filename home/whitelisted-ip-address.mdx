# Managing Whitelisted IPs

To enhance security, you can restrict API access to specific IP addresses. Once at least one IP is added, all requests from other IPs will be blocked.

## 1. Accessing Whitelisted IP Settings

To manage your whitelisted IPs:

1. Log in to your **ClickPesa Dashboard**.
2. Navigate to **Settings** → **Developers**.
3. Locate the **Whitelisted IP addresses** section.

## 2. Managing IP Addresses

- **Add an IP Address**: Specify an IP address to allow API requests from that source.
- **Remove an IP Address**: Deleting an IP from the list will revoke its access to ClickPesa APIs.

<Note>
  🚨 **Important:** - If no IP addresses are added, API requests will be
  accepted from any IP. - Once you add at least one IP address, requests from
  all other IPs will be **blocked**.
</Note>
