## Payments API updates

- Added new optional parameter **`fetchSenderDetails`** to **[payments/preview-ussd-push-request](/api-reference/collection/ussd-push-requests/preview-ussd-push-request)** API endpoint to enable fetching sender details.
  - Type: `boolean`
  - Description: If set to `true` fetch sender details.
  - Default: `false`

</Update>
