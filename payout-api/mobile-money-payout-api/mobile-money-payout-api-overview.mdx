---
title: "Mobile Payouts API"
description: "Send payouts directly to recipients' mobile money wallets."
---

Preview a mobile money payout to confirm the phone number, amount, fee, and available balance. Then create the payout to send funds to the recipient's mobile wallet.

Pay from **TZS** or **USD** (`currency`). Recipients always receive **TZS** — mobile wallets cannot hold USD. When you pay from USD, preview and create responses include `exchanged` and `exchange`.

<Warning>
[Create Mobile Money Payout](/api-reference/disbursement/mno-payout/create-mno-payout) allows one create request every **60 seconds** per merchant. Creating another payout before the cooldown ends returns an error with the remaining wait time. Preview is not affected.
</Warning>

## Prerequisites

1. **API Keys** -
   [Generate API Keys](/application/api-application-setup) for Hosted Checkout integration

2. **Authorization Token** -
   Use **API Keys** to [Generate Authorization Token](/api-reference/authorization/generate-token)
