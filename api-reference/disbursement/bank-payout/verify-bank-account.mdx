---
title: "Verify Bank Account"
openapi: "POST /payouts/verify-bank-account"
---

Verifies a bank account and returns the beneficiary `accountName`. Pass the returned `accountName` when calling [Create Bank Payout](/api-reference/disbursement/bank-payout/create-bank-payout).

```bash
curl --request POST \
  --url https://api.clickpesa.com/third-parties/payouts/verify-bank-account \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "bic": "CORUTZTZ",
    "accountNumber": "0150123456789"
  }'
```

**Example response**

```json
{
  "accountName": "TEMBO SHOP"
}
```
