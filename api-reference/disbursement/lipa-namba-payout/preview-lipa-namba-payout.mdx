title: "Preview Lipa Namba Payout"
openapi: "api-reference/disbursement/lipa-namba-payout/openapi.json POST /payouts/preview-lipa-namba-payout"
---

<Note>
Provide exactly one destination: `lipaNamba` + `providerCode`, or TanQR `qrCode`. Preview must resolve a beneficiary name before you create the payout.
</Note>

<Note>
  If the merchant has not yet received a successful payment or deposit, this endpoint returns `404` with the message: `No balance account is linked to this merchant yet. Balance becomes available after the first successful payment or deposit.`
</Note>
